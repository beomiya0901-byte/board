토큰은 이 기기 브라우저에만 저장돼요. 저장소 파일에는 키워드만 들어가요
토큰 30초 발급 방법
  1. github.com/settings/personal-access-tokens/new 를 엽니다.
  2. Token name에 keyword-studio, Expiration은 원하는 기간을 고릅니다.
  3. Repository access → Only select repositories → studio-sync 선택.
  4. Permissions → Repository permissions → Contents: Read and write 만 켭니다.
  5. Generate token 후 나온 github_pat_… 값을 위 칸에 붙여넣고 [연결 테스트]를 누릅니다.
토큰은 이 브라우저에만 남고 GitHub 파일·백업 JSON에는 들어가지 않아요. 아이폰과 PC에서 각각 한 번씩 넣으면 됩니다.
