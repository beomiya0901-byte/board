# 블로그톡(블톡) 키워드 기능 정리

사용자가 보내 준 블톡 사용가이드(키워드 추천, 키워드 리스트) 원문을 정리한 것. 키워드 작업을 할 때 이 파일을 기준으로 한다.
키워드 분석 가이드는 링크가 홈으로 넘어가서 받지 못했다. 키워드 분석 화면 구성은 SKILL.md 의 "필드 매핑"(사용자 스크린샷 기준)을 따른다.

## 공통

- 숫자 두 종류
  - **키워드 추천 · 키워드 리스트**의 검색량·발행량은 **미리 받아 둔 값**이다. 키워드마다 갱신 시점이 달라 길게는 2주 전 값일 수 있다.
  - **키워드 분석**은 검색한 순간의 **실시간 값**이다.
  - 스튜디오에 숫자를 저장할 때는 반드시 키워드 분석에서 다시 확인한 값을 쓴다.
- 세 갈래 출처(추천·리스트 공통)
  - 내 유효키워드에서: 지금 노출 중인 내 키워드 기반
  - 내 최근 포스팅에서: 최근 글 주제 기반
  - 내 경쟁 블로그에서: 비슷한 블로그들이 노출 중인 키워드. 블로그 카테고리(주제) 기준이라 네이버 블로그에 주제를 설정해 둬야 나온다.
- 블로그를 2개 이상 등록했다면 **기준 블로그**를 골라야 하고, 바꾸면 추천·리스트·새로고침 횟수가 모두 그 블로그 기준으로 바뀐다.
- **키워드 저장소**: 계정당 최대 100개. 추천·리스트에서 '저장하기'로 담는다. 이미 저장된 키워드는 '저장 취소'로 보이고, 한 번 더 누르면 빠진다.

## 키워드 추천 (`/service/keyword-recommend`)

- 하루 **15개**(갈래마다 5개). 처음 들어가면 5개, '새로고침' 1번에 5개씩 더 받는다.
  - 베이직: 새로고침 1번 → 하루 10개
  - 스탠다드·프리미엄: 새로고침 2번 → 하루 15개
- 새로고침을 안 쓰고 날이 바뀌면 **못 받은 몫은 사라진다**. 그날 받을 건 그날 다 받는다.
- 아래 "추천받은 키워드"에 회차별로 모이고, 최대 45개까지 쌓인다. **매일 자정에 비워진다.**
- 한 번 받은 키워드는 5일 동안 다시 나오지 않는다.
- 칸이 비면: 유효키워드가 없거나, 글이 없거나, 블로그 주제가 설정되지 않은 경우다.

## 키워드 리스트 (`/service/keyword-list`, 스탠다드 이상)

추천에 나온 출처의 키워드 **전체**를 조건으로 걸러 보는 화면.

- 순서: 기준 블로그 → **범위 탭**(전체 · 내 유효키워드에서 · 내 최근 포스팅에서 · 내 경쟁 블로그에서, 처음엔 '내 유효키워드에서') → **카테고리**(처음엔 내 블로그 주제 1개) → **상세 필터 10줄** → **'필터 적용하기'**를 눌러야 반영된다. 안 누르면 목록 위에 '적용 전'이 보인다.
- 정렬을 안 고르면 '내 레벨과 비슷한' 순.
- 통합검색에 블로그 자리가 하나도 없는 키워드는 목록에 나오지 않는다.

### 상세 필터 10줄

| 필터 | 뜻 / 쓰는 법 |
| --- | --- |
| 평균 레벨 · 최저 레벨 | 지금 노출 중인 블로그들의 평균·최저 레벨(Lv1~Lv10 체크박스). **최저 레벨 ≤ 내 레벨**이면 내 레벨로도 들어간 블로그가 있다는 뜻. 바로 쓸 키워드를 찾는 핵심 조건 |
| 월간 검색량 · 월간 발행량 | 범위 칩 또는 직접 입력(최소·최대) |
| 누적 발행량 | 지금까지 이 키워드로 쓰인 글 수 |
| 콘텐츠 포화도 | 검색량 대비 글이 쌓인 정도. 낮을수록 빈 키워드. 칩: ~5% · 5~20% · 20~100% · 100%↑ 또는 직접 입력 |
| 평균 발행일 | 상위 글들이 평균 며칠 전 글인지. 오래됐을수록 새 글이 들어갈 틈이 있다 |
| 파워링크 단가 | 광고 단가. 상업적 가치가 큰 키워드를 찾을 때 |
| 통합검색 시작 위치 | 통합검색에서 블로그가 몇 번째부터 나오는지. 작을수록 블로그가 위에 붙어 유입에 좋다 |
| 섹션 | 통합검색 · 클립 · AI브리핑 · 플레이스 · 인플 토픽 · 인플루언서 · 지식iN 중 있는 키워드만(여러 개면 하나라도 있으면) |

- 정렬: 줄마다 높은순·낮은순. 여러 줄을 고르면 누른 순서대로 1·2·3 우선순위가 붙는다(섹션은 거르기만 함).
- 고른 칩을 다시 누르면 해제된다. '필터 초기화'는 상세 필터만 지우고 카테고리는 남긴다.
- 오른쪽 **현재 조건**에 범위·카테고리·필터·정렬·결과 건수가 보인다. 걸린 줄은 초록, 바꾸고 적용 안 한 줄은 주황 '변경'.
- **내 프리셋**: 조건 묶음을 이름 붙여 저장하고, 누르면 카테고리·필터·정렬이 한 번에 바뀐다.

### 결과 표 (11칸)

- 머리글을 누르면 정렬된다. 표 위에서 검색(걸린 조건의 결과 전체에서 찾음), 페이지당 10·30·50개(기본 30), 전체 저장·저장 취소(지금 페이지를 저장소에)를 쓸 수 있다.
- 콘텐츠 포화도: 10% 미만은 초록 굵은 글씨, 100% 이상은 빨간 '100%↑'.
- 통합검색 시작 위치: 숫자 배지(1·2번째는 연한 초록), 없으면 '없음'.
- 섹션: 앞에서부터 3개까지 칩.
- 결과가 없으면 가장 많이 걸러낸 조건 최대 3개와 '풀기' 버튼이 나온다.

## 스튜디오 자동 발굴에 쓰는 기준 (클로드)

1. **매일 첫 실행에서 키워드 추천부터** 연다. 새로고침을 다 써서 그날 15개를 모두 받는다(자정에 사라지고, 못 받은 몫은 이월되지 않는다).
2. 이어서 **키워드 리스트**를 쓴다. 프리셋 이름은 `스튜디오 자동 발굴`, 조건은 아래와 같다. 처음 실행할 때 만들고, 다음부터는 그 프리셋을 누른다.
   - 범위: 전체
   - 카테고리: 내 블로그 주제
   - 최저 레벨: 내 레벨 이하(스튜디오 설정의 `myLevel`, 없으면 이 필터는 건너뛴다)
   - 월간 검색량: 스튜디오 기준(`minVol`) 이상. 결과가 10개 미만이면 기준의 1/3까지 낮춰 다시 본다
   - 콘텐츠 포화도: ~20%
   - 통합검색 시작 위치: 작은 순 우선
   - 정렬: 1) 콘텐츠 포화도 낮은순 2) 월간 검색량 높은순
3. 리스트·추천에서 고른 후보는 **키워드 분석에서 실시간 값으로 다시 확인**한 뒤 스튜디오에 넣는다.
4. 블톡 키워드 저장소(100개 한도)에는 사용자가 따로 말하지 않으면 담지 않는다. 스튜디오가 저장소 역할을 한다.
